# Caber Tattoo — Landing Page Oficial

Landing page moderna, rápida y de estética dark luxury para **Caber Tattoo**, tatuador profesional con sedes en **Avellaneda** y **Villa Elisa** (Buenos Aires, Argentina).

## 🚀 Características

- **Diseño Dark Luxury**: Paleta profunda obsidian (`#08080a`), acentos carmesí tattoo (`#e52538`) y detalles en oro (`#e6b461`).
- **Sedes Dobles**: Información diferenciada y llamadas a la acción para los estudios de **Avellaneda** y **Villa Elisa**.
- **Portfolio / Galería con Lightbox**: Muestra de piezas de alta calidad con filtros interactivos (*Black & Grey*, *Anime/Dark*, *Lettering*, *Cuello/Máscaras*).
- **Cotizador & Agendador Interactivo**: Flujo en 4 pasos donde el usuario elige estudio, estilo, zona del cuerpo y tamaño, armando un mensaje dinámico listo para enviar a WhatsApp.
- **WhatsApp Directo**: Integración con el número oficial **+54 9 11 2723-3546**.
- **Perfil del Artista & Bioseguridad**: Sección dedicada a Caber con foto real en estudio, filosofía y normas estrictas de asepsia.
- **FAQ Interactivo**: Acordeones para resolver dudas previas (turnos, señas, cuidados).

## 🛠️ Cómo Probar Localmente

Simplemente abrir `index.html` en cualquier navegador web moderno, o ejecutar con cualquier servidor local (como Live Server, Vite o Node):

```bash
# Con npx serve o python:
npx serve .
# o
python -m http.server 3000
```
